# 크레이지 아케이드 클론

격자 기반 대전 액션. 물풍선을 놓아 십자 물줄기로 상대를 **물방울에 가두고**,
갇힌 상대를 밟아 제거한다.

설계 문서는 [DESIGN.md](./DESIGN.md)에 있다.

## 조작

| | 이동 | 물풍선 |
|---|---|---|
| 1P | 방향키 | `Space` |
| 2P | `WASD` | `F` |

- `R` — 새 판
- 화면 위 설정 바에서 **개인전 / 2v2**, 사람 인원, 봇 난이도를 고른다 (바꾸면 새 판이 시작된다)
- `1` / `2` — 사람 인원 전환 단축키

**2v2를 한 번은 해보시길.** 아군이 있어야 구출 규칙이 의미를 갖는다.
개인전에서는 갇힌 사람을 풀어줄 이유가 아무에게도 없어서 게임의 절반만 보게 된다.

**물방울에 갇히면 방향키를 좌우로 번갈아 연타**해야 빠져나온다.
같은 방향을 계속 누르면 게이지가 오르지 않는다.

## 규칙 요약

- 물줄기에 맞아도 즉사가 아니라 물방울에 갇힌다 (5초)
- 갇힌 상태에서 벗어나는 길은 셋: 연타로 자력 탈출 / 물줄기가 물방울을 다시 맞힘 / 시간 초과 사망
- **물줄기 재명중은 소유자를 가리지 않는다.** 적이 쏜 것이어도 풀려난다.
  그래서 갇힌 상대를 제거하는 유일한 수단은 **밟기**다
- 3분이 지나면 서든데스 — 바깥부터 나선형으로 블록이 떨어져 맵을 좁힌다

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

### 온라인 (같은 판에서 대전)

터미널 두 개가 필요하다.

```bash
npm run server     # ws://0.0.0.0:8080  — 서버 권위 60Hz, 스냅샷 20Hz
npm run dev        # 클라이언트
```

브라우저에서 하단 **온라인** 칸의 주소를 확인하고 **접속**을 누른다.
탭을 두 개 열면 둘이 같은 판에 들어간다. 최대 4명이고, **빈 자리는 봇이 채운다.**
사람이 나가면 그 자리를 봇이 이어받는다.

**방 코드**를 넣으면 같은 코드끼리 만난다 (비우면 `MAIN`).
주소에 `?room=ABCD`를 붙여 링크를 보내도 된다.
자리(4명)가 차면 거절되지 않고 **관전**으로 들어간다.

다른 기기에서 붙으려면 주소의 `localhost`를 서버 PC의 IP로 바꾸고,
그 PC에서 **5173(클라이언트)과 8080(서버) 두 포트**를 방화벽에서 열어야 한다.

### 서버 배포 (Fly.io)

```bash
fly launch --no-deploy    # fly.toml 이 이미 있으므로 덮어쓰지 말 것
fly deploy
fly status                # https://<앱>.fly.dev/health 로도 확인 가능
```

클라이언트를 배포할 때 서버 주소를 주입한다:

```bash
VITE_SERVER_URL=wss://<앱>.fly.dev npm run build -w @crazy/client
```

> **서버 주소는 반드시 `wss://`** 여야 한다. GitHub Pages는 https라서
> 브라우저가 `ws://` 평문 연결을 mixed content로 차단한다.

```bash
npm test           # 시뮬레이션 테스트 (봇 vs 봇 헤드리스 대전 포함)
npm run typecheck
```

## 구조

```
packages/
  core/     순수 TS 시뮬레이션. DOM 의존 없음
    src/systems/   movement · bubble · explosion · trap · item · suddenDeath · victory
    src/ai/        danger(위험맵) · pathfind(시간 인지 BFS) · bot
  client/   Canvas 2D 렌더 + 키보드 입력 + 온라인 접속
  server/   Node + ws. core의 step()을 60Hz로 권위 실행
```

`core`는 `client`를 import하지 않는다. 시뮬레이션이 60Hz 고정 틱 + 정수 좌표로
결정론적이라, 같은 시드와 같은 입력열은 항상 같은 결과를 낸다.
나중에 온라인을 붙일 때 서버가 이 코드를 그대로 실행하기 위한 전제다.

## 테스터에게

현재는 **각자의 브라우저에서 도는 로컬 게임**이다. 접속자끼리 같은 판에서 만나지 않는다.
지금 듣고 싶은 피드백은 이런 것들:

- 이동이 답답한가? 특히 **코너를 돌 때** 벽에 걸리는 느낌이 있는지
- 물풍선 신관 3초가 길거나 짧은가
- 물방울에 갇혔을 때 5초가 적당한가, 연타 12회가 힘든가
- 봇 난이도 세 단계가 실제로 구분되는가 (쉬움/보통/어려움을 다 해보고)
- 2v2에서 구출이 재미있는가, 아니면 그냥 번거로운가

모바일에서는 화면 아래에 가상 스틱과 물풍선 버튼이 나온다.
격자 4방향 이동이라 스틱은 밀어낸 방향을 **가장 큰 축 하나로 스냅**한다.
